AXIOM 0.5 · x86_64 · READY

Built, not assembled

A real kernel, one layer at a time.

Axiom currently boots into a protected user-space terminal and includes the foundations needed to grow into a complete desktop operating system.

01

Dual-firmware boot

A single hybrid ISO boots through Limine on legacy BIOS and modern UEFI machines.

02

Memory and hardware

Paging, kernel heap, SMP startup, interrupts, ACPI, PCI, AHCI, and NVMe discovery.

03

Storage and files

A bounded VFS, read-only FAT32 support, and persistent journaled AxiomFS v2 storage.

04

Protected user space

Ring-3 ELF programs, isolated address spaces, preemptive scheduling, IPC, and syscall ABI v1.

05

Accounts and security

Graphical login, password verifiers, users and groups, permissions, scoped elevation, and auditing.

06

Tested startup

Every critical subsystem visibly moves from not tested, to testing, to OK before login.

Try it in a virtual machine

One command to build.

Use Arch WSL or another compatible Linux environment. The build script checks its tools, performs a clean rebuild, and places the hybrid image beside the README.

Axiom is experimental. Test it in QEMU before considering real hardware, and never use a disk containing important data.

WSL / Linux
$ git clone https://github.com/Vvoidddd/Axiom.git
$ cd Axiom
$ ./all

Axiom build complete: axiom.iso
